# 双人手机体感手柄

用 Godot 4 打开 `project.godot` 并按 F5。电脑和两部手机连同一个 Wi-Fi，每部手机扫码进入各自的玩家席位。打开手柄后即可拖动左侧摇杆，同时按住右侧的 A、B、X、Y。Godot 会分别显示两位玩家的摇杆位置和按键状态。摇杆回中时两轴为 0，向右时 X 为正，向上时 Y 为正，两轴范围均为 −1 至 1。

手机点「开启传感器」并授权后，Godot 也会显示去重力加速度和含重力加速度（X、Y、Z，m/s²），以及陀螺仪角速度（浏览器的 α、β、γ，°/s）。每位玩家的 3D 手机模型会跟随浏览器提供的设备姿态。转动手机即可看到模型变化，暂时收不到姿态时会显示「等待姿态数据」。

手机浏览器需要受信任的 HTTPS。每部手机首次接入时，按扫码页里对应系统的说明安装并信任本地证书，再点「打开手柄」。iPhone 请用 Safari，Android 请用 Chrome。证书保存在 Godot 的项目用户数据目录，日常重启项目无需重复安装。后续扫码可直接点「打开手柄」。[Apple 的证书信任设置说明](https://support.apple.com/zh-cn/102390)

- 手柄页在前台时持续采集。松手后摇杆自动回中，断线后清除按键和摇杆状态。浏览器没提供或停止发送的传感器读数会显示为「—」。
- 网页、证书下载和加密 WebSocket 都由 Godot 在电脑上提供。三个端口默认使用 TCP 8810、8811、8812，占用时自动尝试下一组三个端口，最高到 8824。整个流程无需公网。
- macOS 使用系统自带的 OpenSSL。其他系统需要在 PATH 中提供 OpenSSL。若需导出桌面应用，请在 Godot 的导出资源过滤器中包含 `web/*.html, web/*.mobileconfig`。
- 手机打不开扫码页时，检查电脑防火墙及 Wi-Fi 是否允许设备互访。有多个网卡时，在 Godot 窗口点「切换地址」。电脑更换 Wi-Fi 或 IP 后，重启 Godot 生成新的二维码和服务器证书。
